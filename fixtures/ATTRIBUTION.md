# Demonstration photographs

The live proofs file these photographs as claim evidence. Each one is used
unmodified apart from its width, chosen by Wikimedia Commons, and a JFIF header
segment added where the file lacked one (see `scripts/fixtures.mjs`). None of
them shows a real claim: the stories the proofs tell around them are invented
for the demonstration.
